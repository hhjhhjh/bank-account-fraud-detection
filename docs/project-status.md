# BAF 프로젝트 진행 기록과 평가 계획

2026년 11월 26일 기준으로 여섯 모델의 학습률 0.001·세 시드 전체 학습과 Validation 비교를 마쳤습니다. 현재 조건에서는 FT-Transformer가 평균 AP와 FPR 1%·5% 조건의 평균 Recall에서 가장 높았습니다. 기존 중간발표 결과와 E1의 XAI는 보존합니다. 제한적 학습률 탐색 도구를 준비했으며, 탐색과 최종 Test 평가는 아직 실행하지 않았습니다.

이 문서는 현재 진행 상황과 남은 작업을 기록합니다. 최신 비교는 [공통 학습률 보고서](../results/reference/fixed-lr-comparison/report.md)와 그 안의 원본 JSON·CSV를 참조합니다. 기존 [손실함수 실행 기록](../results/reference/mlp-loss-comparison/runs.json)과 [모델 구조 실행 기록](../results/reference/mlp-architecture-comparison/runs.json)도 유지합니다.

## 데이터와 학습 조건

| 분할 | 월 | 행 수 | 사기 건수 |
|---|---|---:|---:|
| Train | 0~5 | 794,989 | 8,151 |
| Validation | 6 | 108,168 | 1,450 |
| Test | 7 | 96,843 | 1,428 |

정답과 월은 모델 입력에서 제외했습니다. 수치형은 Train 중앙값으로 채우고 Train에서 fit한 StandardScaler를 적용했습니다. 결측 표시 열, 이진형, 원핫 인코딩 결과는 0/1을 유지합니다. 공식 문서의 특수 결측 규칙과 미래 분할에서 처음 나타나는 결측에 대한 경고를 구현했습니다. 전처리 후 입력은 57개 특성입니다.

학교 GPU의 비교 실험은 RTX A5000, PyTorch 2.10.0+cu130에서 실행했습니다. 시드 42·43·44, 배치 크기 256, AdamW, 학습률 0.001, 최대 20에포크, 조기 종료 patience 5를 사용했습니다. 각 실행의 최고 Validation AP 체크포인트를 저장했습니다.

평균과 표준편차는 세 시드에서 계산했습니다. 시간은 각 실행이 종료될 때까지의 학습과 검증을 합한 값이며, 조기 종료에 따라 에포크 수가 다릅니다.

E1은 Train의 정상·사기 건수 비율인 96.532695를 양성 클래스 가중치로 사용했습니다. E2는 시드 42에서 감마 0.25와 0.5~4.0을 탐색했습니다. 감마 0.5가 가장 높았고, 추가 시드 43·44에서도 초기 감마 2.0보다 높은 AP를 기록했습니다. E2의 시드 42 결과에는 감마 선택의 영향이 포함됩니다.

E1은 B0보다 평균 AP가 0.002844 높았습니다. E1과 E3의 파라미터 수는 각각 15,745개와 15,826개이며, E3는 세 시드 모두 E1보다 AP가 낮았습니다. 이번 비교에서는 E1을 중간발표 XAI 대상으로 선정했습니다. 최종 모델은 E4·E5의 Validation 비교까지 마친 뒤 정합니다.

기존 중간발표 실행과 추가 두 모델의 전체 학습 여섯 실행에 대한 로그 및 best.pt·last.pt를 로컬 checkpoints 폴더에 백업했습니다. 학습률 탐색 도구 보완 후 전체 테스트 113개가 통과했습니다. 원본 데이터·전처리 배열·가중치는 Git 추적에서 제외하고, 설정·집계 지표·보고서를 저장소에서 관리합니다.

## 평가 기준

AP를 모델과 체크포인트의 주 선정 지표로 사용합니다. 판정 임계값이 필요한 지표는 다음 두 조건으로 평가합니다.

| 기준 | 목적 |
|---|---|
| Recall @ Validation FPR ≤ 1% | 최초 계획의 엄격한 오탐 제한에서 탐지 성능을 측정합니다. |
| Recall @ Validation FPR ≤ 5% | BAF 원 논문과 같은 오탐 허용 수준의 보조 지표로 탐지 성능을 측정합니다. |

FPR은 정상 신청 중 사기로 잘못 판정한 비율입니다. Recall은 실제 사기 중 탐지한 비율입니다. BAF 원 논문은 FPR 5%에서 TPR, 즉 Recall을 측정했습니다. 우리 연구는 월 6을 Validation, 월 7을 Test로 사용하는 별도 분할이므로 논문 수치와 비교할 때 분할 차이를 밝힙니다. [BAF 원 논문 §3.2](https://papers.nips.cc/paper_files/paper/2022/file/d9696563856bd350e4e7ac5e5812f23c-Paper-Datasets_and_Benchmarks.pdf)

각 체크포인트에 대해 Validation에서 FPR 상한을 만족하면서 Recall이 가장 높은 임계값을 선택합니다. 같은 점수의 표본은 함께 판정하며, Recall이 같은 후보에서는 FPR이 더 낮은 값을 선택합니다. 분류 규칙은 점수가 임계값 이상이면 사기로 판정하는 방식으로 고정합니다.

5%와 1%에서 고른 두 임계값을 Test에 각각 그대로 적용합니다. Test에서는 FPR이 상한을 넘을 수 있으므로 실제 FPR, Recall, 오탐 건수와 사기 누락 건수를 함께 보고합니다. Test 결과로 모델·감마·임계값을 다시 선택하지 않습니다.

## 중간발표 준비

[분석 보고서](../results/midterm/report.md)에 Validation 지표와 원본 파일, 그래프별 해석, IG 결과와 한계를 기록했습니다. [발표 구성](../results/midterm/presentation-notes.md)은 11월 26일 발표를 10장·8분으로 배분합니다.

B0~E3의 12개 체크포인트를 같은 평가 코드로 비교했습니다. AP와 FPR 1%의 평균 Recall은 E1이 가장 높고, FPR 5%의 평균 Recall은 B0가 조금 높았습니다. 각 임계값은 전체 동점 그룹을 포함하며 Recall이 같으면 FPR을 최소화합니다. 중간발표 평가와 XAI 실행에서 Test 배열을 열면 실패하는 검사를 적용했습니다.

E1 시드 42의 사기 logit을 Train 평균 입력 baseline에서 Integrated Gradients로 설명했습니다. 시드 42로 추출한 Validation 256건과 TP·FN·FP 각 1건을 분석하고, 사기 중심으로 TP·FN 각 100건을 추가 비교했습니다. 50건·100건 및 겹치지 않는 50건씩의 민감도 점검을 함께 기록했습니다. 범주형·이진형의 평균 벡터는 실제 신청과 일치하지 않을 수 있습니다. IG 합과 logit 차이의 수치 오차, 원래 특성 단위 집계, 표본 선택 규칙을 결과에 저장했습니다.

## E4 로컬 개발

MLP+BCE의 Train 전용 Random Oversampling을 구현했습니다. 비율 0.1은 초기 동작 확인용이며, 중복 행은 시드로 고정하고 Validation에는 기존 분할을 적용합니다. 비율 변경은 체크포인트 재개 시 검사합니다.

로컬 CPU에서 원래 Train 20,000건을 에포크당 21,775건으로 늘렸고, Validation 10,000건을 사용했습니다. 학습을 2에포크에서 저장한 뒤 3에포크까지 재개하고 저장 모델의 AP 0.113750을 재현했습니다. 이 값은 소규모 기능 검증 결과입니다.

[실행 확인 기록](../results/reference/oversampling-check.json)에 원래 분할과 샘플링 후 학습량을 저장했습니다. 전체 데이터의 비율 0.1·0.25·0.5·1.0에 대한 표본 수와 배치 수는 학습량 예상치입니다. 실제 전체 학습은 비율 0.1·학습률 0.001에서 세 시드로 실행했고, 평균 AP는 0.165475였습니다. 이후 학습률 탐색에서는 비율 0.1을 고정합니다.

## E5 로컬 개발

기존 57개 입력을 수치 토큰으로 바꾸는 FT-Transformer를 구현했습니다. 토큰 너비 32, head 4개, 블록 2개, ReGLU FFN 너비 48인 초기 모델의 학습 파라미터는 21,889개입니다. Attention과 FFN dropout은 0.1이며 residual dropout은 0입니다. 손실함수와 최적화 조건은 E1에서 가져왔으며, 이 구조와 설정은 아직 전체 데이터에서 선정하지 않았습니다.

CPU에서 Train 2,000건·사기 21건과 Validation 1,000건·사기 13건을 사용했습니다. 배치 크기 64로 1에포크를 실행한 뒤 2에포크까지 재개했습니다. 저장한 최고 모델을 다시 불러와 Validation AP 0.022733을 재현했으며, 입력에 대한 기울기가 유한한지도 확인했습니다. 사기 표본이 적고 학습도 짧으므로 이 값은 기능 검증에만 사용합니다. Test 배열은 열지 않았습니다.

[실행 확인 기록](../results/reference/ft-transformer-check.json)에 설정·실행 명령·손실·AP·시간·데이터 해시를 저장했습니다. 합성 데이터 테스트에서는 연속 학습과 중단 후 재개의 손실·AP·모델 가중치가 일치했습니다. 설정을 바꿔 재개하면 오류를 내며, 평가용 모델 로더에서도 E5를 복원합니다.

[원 논문](https://arxiv.org/abs/2106.11959)과 [연구자 코드](https://github.com/yandex-research/rtdl/blob/main/rtdl/modules.py)의 토큰화·Attention·ReGLU·CLS 구조를 참고했습니다. 비교 조건을 유지하기 위해 범주형 임베딩 대신 기존 원핫 열마다 수치 토큰을 만들었습니다. PyTorch MultiheadAttention을 사용하고 KV 압축과 마지막 층의 CLS 전용 query 최적화는 넣지 않았습니다. 기존 MLP처럼 모든 파라미터에 AdamW weight decay를 적용하며, 논문에서 사용하는 파라미터별 제외 규칙은 적용하지 않았습니다. 따라서 원 논문의 성능 재현과 구분해 보고합니다.

학교 GPU에서 같은 구조와 Weighted BCE, 학습률 0.001로 세 시드 전체 학습을 실행했습니다. 평균 AP는 0.179754였고 학습·검증 시간은 평균 428.79초였습니다. Validation FPR 1% 조건의 평균 Recall은 24.276%, 5%에서는 52.690%였습니다. 이 결과만으로 최종 모델을 확정하지 않고 학습률 탐색을 이어갑니다.

## 제한적 학습률 탐색

기본 MLP부터 Random Oversampling까지는 0.0003·0.001·0.003, FT-Transformer는 0.0001·0.0003·0.001을 비교합니다. 기존 감마 0.5, 오버샘플링 비율 0.1과 현재 모델 구조를 유지합니다. 시드 42에서 반올림 전 Validation AP로 선정하며 정확한 동률이면 0.001, 그 값이 없으면 낮은 학습률을 우선합니다. 실행 명령은 [README](../README.md)의 학습률 탐색 절에 있습니다.

학습률 선정 뒤 시드 43·44를 추가하고 시드 42를 포함한 평균과 표본 표준편차를 보고합니다. 선정에 쓴 시드가 반복 보고에도 포함되는 한계를 밝힙니다. 학습률 후보 수만 같게 제한했으므로 기존 감마 탐색을 포함한 전체 튜닝 비용까지 같다고 주장하지 않습니다. 20에포크 상한 도달과 조기 종료를 구분하고, 모든 학습·체크포인트·Validation 임계값을 확정한 뒤 Test를 평가합니다.

## XAI 확장과 후속 연구

중간발표의 IG를 최종 모델에 확장하고 정상·사기 표본의 기여도 차이와 TP·TN·FP·FN을 분석합니다. 가능하면 소규모 baseline 민감도 분석을 추가합니다. 관측된 기여도와 분포 차이는 모델 예측에 대한 설명으로 제시합니다.

SHAP과 Precision@K·Recall@K는 B0~E5 및 핵심 XAI를 마친 뒤 여유가 있을 때 검토합니다. CTGAN 기반 사기 데이터 증강은 E6 후속 연구 후보로 유지하며, 생성 데이터 품질·중복·분포와 BAF 자체의 합성 데이터 특성을 검증하는 별도 작업이 필요합니다.

최종 보고서에는 시간 분할, 추가 튜닝 예산 차이, 단일 월 Test와 세 시드 실험의 범위, 작은 표본·baseline에 의존한 XAI의 한계를 기록합니다.
