# BAF Base MLP 손실함수 비교

학교 GPU의 시드 세 개에서 Weighted BCE(E1)가 모두 가장 높은 Validation AP를 기록했습니다. Residual MLP(E3)에는 Weighted BCE를 적용하고, E1의 MLP를 비교 기준으로 사용합니다.

2026년 11월 12일까지의 학습 기록은 [runs.json](runs.json)에 있습니다. 로컬 CPU 검증 6회와 학교 GPU 실행 20회에서 나온 에포크별 Train 손실, Validation 손실, Validation AP를 담았습니다.

## 실험 조건

[Phase 1에서 검증한 BAF Base](../baf-base/)를 사용했습니다. Train은 월 0~5의 794,989건, Validation은 월 6의 108,168건입니다. 두 분할의 사기는 각각 8,151건과 1,450건입니다. 모델과 체크포인트는 Validation AP로 선택했고, 월 7의 Test는 최종 평가용으로 보관했습니다.

세 실험은 입력 특성 57개, 은닉층 크기 128·64, 드롭아웃 0.1인 동일한 MLP를 사용했습니다. AdamW, 학습률 0.001, 가중치 감쇠 0.0001, 배치 크기 256을 사용했습니다. 모델 비교와 감마 탐색의 상한은 20에포크이며, Validation AP가 5에포크 연속 개선되지 않으면 조기 종료했습니다. Validation 손실은 모든 실험에서 가중치 없는 BCE로 계산했습니다.

| 실험 | 학습 손실 | 적용 설정 |
|---|---|---|
| B0 | 기본 BCE | 클래스 가중치를 적용하지 않았습니다. |
| E1 | Weighted BCE | Train의 정상 786,838건을 사기 8,151건으로 나눠 `pos_weight=96.532695`를 적용했습니다. |
| E2 | Focal Loss | 클래스별 고정 가중치 없이 감마를 적용했습니다. |

학교 GPU는 NVIDIA RTX A5000이며, PyTorch 2.10.0+cu130과 기본 정밀도로 실행했습니다. 로컬 CPU에서는 PyTorch 2.15.0을 사용했습니다.

## 학교 GPU의 손실함수 비교

각 칸은 해당 시드에서 가장 높았던 Validation AP입니다. 표준편차는 표본 표준편차입니다.

| 실험 | 시드 42 | 시드 43 | 시드 44 | 평균 | 표본 표준편차 |
|---|---:|---:|---:|---:|---:|
| B0 기본 BCE | 0.168050 | 0.169070 | 0.168323 | 0.168481 | 0.000528 |
| E1 Weighted BCE | **0.170619** | **0.173364** | **0.169991** | **0.171325** | 0.001794 |
| E2 Focal Loss, 감마 0.5 | 0.170116 | 0.172695 | 0.167614 | 0.170141 | 0.002541 |

같은 시드끼리 비교했을 때 E1의 평균 AP는 B0보다 0.002844, E2보다 0.001184 높았습니다. 시드 42는 E2 감마 탐색에 사용했습니다. 시드 43·44에서도 E1이 E2보다 높았습니다. 이 결과로 E3에 적용할 손실함수를 골랐으며, E3에서는 E1과 손실함수·분할·시드·학습 설정을 맞춥니다.

## Focal Loss 감마 탐색

시드 42에서 0.5~4.0을 0.5 간격으로 실행했습니다. 가장 높은 AP가 하한인 0.5에서 나와 0.25를 추가했습니다.

| 감마 | 최고 Validation AP | 최고 에포크 | 종료 에포크 |
|---:|---:|---:|---:|
| 0.25 | 0.169176 | 11 | 16 |
| 0.5 | **0.170116** | 12 | 17 |
| 1.0 | 0.166708 | 4 | 9 |
| 1.5 | 0.166611 | 11 | 16 |
| 2.0 | 0.169993 | 11 | 16 |
| 2.5 | 0.167655 | 3 | 8 |
| 3.0 | 0.165197 | 11 | 16 |
| 3.5 | 0.167444 | 3 | 8 |
| 4.0 | 0.166369 | 3 | 8 |

탐색 최고값 0.5와 초기 설정 2.0의 차이는 시드 42에서 0.000123이었습니다. 두 값을 시드 43과 44에서 다시 실행했습니다.

| 시드 | 감마 0.5 | 감마 2.0 | AP 차이 |
|---:|---:|---:|---:|
| 43 | 0.172695 | 0.168078 | +0.004617 |
| 44 | 0.167614 | 0.166808 | +0.000806 |

추가 시드 두 개에서도 0.5가 앞서 E2 비교값으로 사용했습니다. 세 시드 평균은 감마 0.5에서 0.170141, 초기 감마 2.0에서 0.168293이었습니다.

## 실행 검증

| 환경과 실행 | 데이터 범위 | 최고 Validation AP | 종료 에포크 |
|---|---|---:|---:|
| Mac CPU B0 첫 실행 | Train 20,000건·Validation 10,000건 | 0.094879 | 2 |
| Mac CPU B0 체크포인트 재개 | 같은 표본 | 0.110308 | 3 |
| Mac CPU B0 전체 데이터 확인 | 전체 Train·Validation | 0.151815 | 1 |
| Mac CPU B0 비교 | 전체 Train·Validation | 0.166473 | 12 |
| Mac CPU E1 비교 | 전체 Train·Validation | 0.172679 | 13 |
| Mac CPU E2 비교, 감마 2.0 | 전체 Train·Validation | 0.167252 | 16 |
| 학교 GPU B0 CUDA 확인 | 전체 Train·Validation | 0.151326 | 1 |

Mac CPU에서 전체 데이터 1에포크의 학습·검증에 1.33초, 명령 시작부터 종료까지 3.65초가 걸렸습니다. 프로세스 최대 상주 메모리는 약 638 MiB였습니다. 학교 GPU의 시드 42에서 학습·검증에 걸린 시간은 B0 58.96초, E1 53.08초였습니다. 시드와 감마를 바꾸는 명령은 작은 BAF 표본에서도 검증했습니다.

## 기록과 재현

26회 실행의 `metrics.json`을 기준으로 지표와 시간을 기록했습니다. 평균과 표준편차는 로그의 값을 반올림하기 전에 계산했습니다. 시간은 각 에포크의 학습과 검증을 합한 값입니다.

[데이터 준비와 실행 방법](../../../README.md)을 따라 Train·Validation 배열을 준비합니다. 파일 해시는 `runs.json`에서 확인할 수 있습니다. 아래 명령은 학교 GPU에서 E2의 감마 0.5를 시드 43으로 반복하는 예입니다. B0·E1은 각각 [B0 설정](../../../configs/b0.toml)과 [E1 설정](../../../configs/e1.toml)을 사용합니다.

```bash
baf-train --config configs/e2.toml --device cuda --batch-size 256 \
  --seed 43 --focal-gamma 0.5 --run-name school-e2-gamma0.5-seed43
```
