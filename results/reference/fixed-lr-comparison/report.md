# 공통 학습률 모델 비교

학습률 0.001 조건에서 FT-Transformer가 세 시드 평균 Validation AP와 FPR 1%·5% 조건의 평균 Recall에서 가장 높았습니다. 이 결과는 고정한 설정에서의 비교이며, 모델별 학습률 탐색과 최종 Test 평가는 아직 실행하지 않았습니다.

## 실험 조건

2026년 11월 26일에 로컬로 복사한 학교 GPU 실행 기록과 체크포인트를 검증하고, 월 6 Validation 108,168건을 CPU에서 다시 평가했습니다. 사기는 1,450건입니다. Train은 월 0~5의 794,989건이며 전처리 입력은 57개입니다. 기존 중간발표 결과와 가중치는 보존했습니다. 평가에서는 Train·Validation 배열만 열었고 Test 배열 접근은 검사로 차단했습니다.

학교 학습은 RTX A5000, PyTorch 2.10.0+cu130, 배치 크기 256, AdamW, 학습률 0.001, 최대 20에포크, 조기 종료 patience 5, 시드 42·43·44를 사용했습니다. E2 감마는 0.5, E4 사기/정상 비율은 0.1입니다. E5는 E1과 같은 Weighted BCE를 사용하며, 기존 원핫 열을 포함한 57개 스칼라 입력을 수치 토큰으로 바꿉니다. 범주형 임베딩을 사용하는 원 논문의 모든 조건을 재현한 실험은 아닙니다.

Validation은 PyTorch 2.15.0의 CPU, 배치 크기 256으로 재추론했습니다. 재추론 AP와 학교 학습 기록의 최대 절대 차이는 5.34e-07입니다. 학습률 선정에는 각 실행의 원래 학습 로그 AP를 사용하며, 아래 지표는 같은 평가 환경에서 재추론한 값입니다.

FPR 임계값은 각 모델·시드의 Validation에서 Recall을 최대화하고, Recall이 같은 후보에서는 FPR을 최소화해 정했습니다. 같은 점수의 표본은 함께 판정하며 `logit >= threshold`이면 사기로 판단합니다. 이 임계값은 이번 고정 학습률 결과의 임계값입니다. 학습률 탐색 후 선정 모델의 임계값은 Test 전에 다시 Validation에서 확정합니다.

## 해석과 한계

FT-Transformer는 Weighted BCE MLP보다 평균 AP가 약 0.008429 높았으며 같은 시드끼리 비교해도 세 번 모두 높았습니다. FPR 1% 조건에서는 평균 사기 탐지가 336건에서 352건으로 늘었습니다. FPR 5% 조건에서는 기존 최고였던 기본 MLP의 평균 745건보다 많은 764건을 탐지했습니다. 개선 후에도 FPR 1%에서 평균 1,098건, FPR 5%에서 평균 686건의 사기를 놓칩니다.

FT-Transformer의 평균 학습·검증 시간은 428.79초로 Weighted BCE MLP의 50.88초보다 길었습니다. 구조뿐 아니라 파라미터 수와 조기 종료 에포크도 다르므로 시간 차이나 성능 차이를 Attention 하나의 효과로 단정하지 않습니다.

Random Oversampling은 비율 0.1·학습률 0.001에서 기본 MLP보다 낮은 AP를 기록했습니다. 이는 현재 비율과 학습률의 조합에 대한 결과입니다. 모든 오버샘플링 비율이 효과 없다는 결론으로 확대하지 않습니다. 에포크당 학습 표본은 794,989건에서 865,522건으로 늘었고, 기존 사기 사례의 반복이 포함됩니다.

E2에는 기존 감마 탐색 비용이 포함됩니다. 이후 학습률 후보 수를 같게 주더라도 전체 튜닝 비용까지 동일하다고 주장하지 않습니다. 시드 세 개와 단일 Validation 월의 결과를 바탕으로 통계적으로 확정된 우위나 최종 Test 성능을 주장하지 않습니다. 기존 E1의 Integrated Gradients 분석은 보존하고 최종 XAI 대상은 학습률 탐색 이후 Validation 기준으로 선정합니다.

## 재현

원래 전처리 배열과 기존 학교 GPU 체크포인트가 필요합니다. 새 학습 없이 메타데이터를 검증하고 Validation만 재평가합니다.

```bash
PYTHONPATH=src python -m baf.lr_search baseline
OMP_NUM_THREADS=2 PYTHONPATH=src python -m baf.evaluation --config configs/fixed-lr-validation.toml
PYTHONPATH=src python -m baf.fixed_lr_plots
```

학습률 탐색은 별도 출력 경로를 사용합니다. 기존 `results/midterm`과 고정 학습률 체크포인트를 덮어쓰지 않습니다.
