# BAF Base MLP 구조 비교

학교 GPU에서 같은 시드 세 개로 비교한 결과, Weighted BCE를 사용한 E1 MLP가 E3 Residual MLP보다 모든 시드에서 높은 Validation AP를 기록했습니다. 최종 평가에는 E1을 사용합니다.

2026년 11월 12일의 E3 기록은 [runs.json](runs.json)에 있습니다. 로컬 CPU 검증 1회와 학교 GPU 실행 3회의 에포크별 손실, Validation AP, 소요 시간을 담았습니다. 대응하는 E1 지표는 [손실함수 비교 기록](../mlp-loss-comparison/runs.json)에 있습니다.

## 비교 조건

E1과 E3는 같은 BAF Base Train·Validation 파일, Weighted BCE, AdamW, 시드 42·43·44, 배치 크기 256, 최대 20에포크, 조기 종료 기준 5에포크를 사용했습니다. 비교 전에 전처리 파일 해시와 구조 외 학습 설정을 원본 로그에서 대조했습니다. 학교 GPU는 NVIDIA RTX A5000이며, PyTorch 2.10.0+cu130과 기본 정밀도로 실행했습니다.

| 실험 | 구조 | 학습 파라미터 수 |
|---|---|---:|
| E1 | 은닉층 크기 128·64인 MLP | 15,745 |
| E3 | 너비 75, 잔차 블록 하나인 Residual MLP | 15,826 |

잔차 블록은 두 선형층으로 계산한 변환값을 입력에 더합니다. 두 모델의 파라미터 수 차이는 약 0.5%입니다. 층 수와 너비도 달라지므로 결과는 두 모델 구조 전체의 비교로 해석합니다.

## 학교 GPU 결과

Validation AP는 각 실행의 최고값입니다. 소요 시간은 종료까지 모든 에포크의 학습과 검증을 합한 값입니다.

| 시드 | E1 AP | E3 AP | E3 − E1 AP | E1 시간(초) | E3 시간(초) | 종료 에포크 |
|---:|---:|---:|---:|---:|---:|---:|
| 42 | 0.170619 | 0.169189 | −0.001430 | 53.08 | 69.64 | 13 |
| 43 | 0.173364 | 0.171878 | −0.001486 | 57.57 | 63.94 | 12 |
| 44 | 0.169991 | 0.168609 | −0.001382 | 41.99 | 50.02 | 11 |
| 평균 | **0.171325** | **0.169892** | **−0.001433** | **50.88** | **61.20** | |
| AP 표본 표준편차 | 0.001794 | 0.001744 | | | | |

두 모델은 각 시드에서 같은 에포크에 조기 종료했습니다. E3는 평균 10.32초 더 걸렸으며, 평균 AP 차이는 0.001433이었습니다.

## 로컬 검증과 최종 평가

Mac CPU에서 E3는 전체 Train·Validation 데이터로 시드 42를 실행했습니다. 8에포크에서 최고 AP 0.170228을 기록했고 13에포크에서 종료했습니다. 저장한 가중치를 불러와 같은 AP를 재현했습니다.

[README의 학습 방법](../../../README.md#mlp-학습)과 [E3 설정](../../../configs/e3.toml)으로 실행을 재현할 수 있습니다. 최종 평가에서는 E1의 판정 임계값을 Validation에서 정하고 Test에 고정 적용합니다.
