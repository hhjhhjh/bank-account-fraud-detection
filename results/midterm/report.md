# BAF 중간발표 분석 결과

E1 Weighted BCE는 Validation AP와 FPR 1% 조건의 평균 Recall에서 가장 높았습니다. FPR 5% 조건에서는 B0의 평균 Recall이 조금 높았습니다. 중간발표에서는 AP 순위와 특정 오탐률에서의 탐지율 순위가 달라진 결과, 여전히 남은 사기 미탐, 초기 XAI를 함께 설명합니다.

이 기록은 2026년 11월 19일에 기존 학교 GPU 체크포인트를 Mac CPU에서 추론해 작성했습니다. 모델별 시드 42·43·44의 Validation 108,168건을 동일한 코드로 평가했습니다. 사기는 1,450건이고 정상은 106,718건입니다. 중간발표 분석에서는 월 6 Validation만 평가했습니다.

AP는 사기 점수 순으로 신청을 살펴볼 때 Precision과 Recall의 관계를 요약한 지표입니다. Precision은 사기로 예측한 신청 중 실제 사기의 비율, Recall은 실제 사기 중 탐지한 비율입니다. FPR은 실제 정상 신청 중 사기로 잘못 예측한 비율입니다.

## 기존 결과 대조

B0~E3의 12개 best.pt를 재사용했습니다. 전처리 파일 해시, 실험 ID, 시드, 모델 입력 차원, 저장된 최고 에포크를 확인했고, 재추론 AP와 학습 로그 AP의 최대 절대 차이는 약 8.53×10⁻⁸이었습니다. 학교 CUDA 학습은 PyTorch 2.10.0+cu130, 이번 CPU 추론은 PyTorch 2.15.0을 사용해 마지막 자릿수가 조금 달라질 수 있습니다.

임계값은 사기 logit에서 선택했습니다. logit은 사기 확률로 변환하기 전의 모델 점수입니다. 같은 점수의 표본을 함께 판정하고, 점수가 임계값 이상이면 사기로 판정했습니다. 각 FPR 상한에서 Recall을 최대화한 다음, Recall이 같은 후보 중 FPR이 더 낮은 임계값을 골랐습니다. 보간으로 동점 표본 일부를 나누는 처리는 하지 않았습니다.

## Validation 비교

표의 편차는 같은 세 시드의 표본 표준편차입니다. Recall 편차의 단위는 퍼센트포인트입니다.

| 모델 | AP 평균 ± 표본 표준편차 | FPR ≤ 1% Recall 평균 ± 편차 | FPR ≤ 5% Recall 평균 ± 편차 |
|---|---:|---:|---:|
| B0 MLP + BCE | 0.168481 ± 0.000528 | 22.897% ± 0.182 | **51.379% ± 0.365** |
| E1 MLP + Weighted BCE | **0.171325 ± 0.001794** | **23.172% ± 0.119** | 51.080% ± 0.279 |
| E2 MLP + Focal Loss, 감마 0.5 | 0.170141 ± 0.002541 | 22.529% ± 0.326 | 51.080% ± 0.829 |
| E3 Residual MLP + Weighted BCE | 0.169892 ± 0.001744 | 22.851% ± 0.380 | 51.264% ± 0.670 |

E1의 AP는 B0보다 0.002844 높았습니다. E1은 FPR 1%에서 B0보다 Recall이 약 0.276퍼센트포인트 높았으며, 사기 1,450건 중 평균 4건을 더 탐지했습니다. FPR 5%에서는 B0가 E1보다 Recall이 약 0.299퍼센트포인트 높았고 평균 약 4.33건을 더 탐지했습니다.

AP는 PR 곡선 전반의 순위를 요약하고, 낮은 FPR에서의 Recall은 선택한 한 임계값 부근의 성능을 측정합니다. 서로 다른 순위가 나온 것은 이 평가 범위의 차이와 일치합니다. 클래스 가중치가 E1의 사기 학습 신호를 늘렸을 가능성은 있으나, 현재 로그로 내부 학습 과정의 원인을 확정할 수는 없습니다.

E1 시드 42의 혼동행렬은 다음과 같습니다. 행은 실제 정상·사기, 열은 예측 정상·사기 순입니다.

| FPR 상한 | logit 임계값 | 실제 FPR | Precision | Recall | F1 | TN | FP | FN | TP |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|
| 1% | 2.688155 | 0.9923% | 24.032% | 23.103% | 0.235584 | 105,659 | 1,059 | 1,115 | 335 |
| 5% | 1.464045 | 4.9870% | 12.149% | 50.759% | 0.196058 | 101,396 | 5,322 | 714 | 736 |

FPR 상한을 완화하면 이 시드에서 401건의 사기를 추가 탐지했고 정상 신청 오탐은 4,263건 늘었습니다. 5% 조건에서도 실제 사기의 약 절반이 미탐으로 남아, AP 개선만으로 연구 성과를 설명하기에는 한계가 있습니다.

각 모델·시드의 임계값, 지표와 혼동행렬은 [validation.json](validation.json)과 [시드별 표](validation_by_seed.csv)에 있습니다. 평균과 표본 표준편차는 [집계표](validation_summary.csv)에 있습니다.

## Integrated Gradients 초기 결과

E1 시드 42의 사기 logit을 Captum 0.9.0 Integrated Gradients로 설명했습니다. baseline은 전체 Train의 전처리 입력 평균입니다. 범주형 원핫과 이진 열에는 중간값이 들어가므로 실제 신청 한 건과 일치하지 않을 수 있습니다.

Validation에서 시드 42로 클래스 비율을 유지한 256건을 추출했습니다. 이 표본의 사기는 3건이므로 전체 중요도는 주로 정상 신청의 설명을 반영합니다. 별도로 FPR 5%의 TP·FN·FP에서 각 유형의 logit 중앙값에 가장 가까운 사례를 골랐습니다. 총 259건을 설명했고, 표본 행 인덱스와 원본 행 ID를 로컬 결과에 보관했습니다.

원핫 열과 결측 표시 열의 signed attribution을 원래 특성별로 합친 뒤, 표본별 절댓값을 평균했습니다. 다른 부호의 열이 합산 과정에서 상쇄될 수 있어 인코딩 열별 평균 절대 기여도도 함께 저장했습니다.

## 사기 탐지·미탐 집단 비교

사기 표본이 3건인 전체 신청 분석을 보완하려고 모델이 탐지한 사기인 TP 100건과 놓친 사기인 FN 100건을 별도로 설명했습니다. E1 시드 42의 FPR 5% 임계값에서 TP 736건, FN 714건 중 각각 100건을 시드 42로 비복원 무작위 추출했습니다. 같은 체크포인트, 사기 logit, Train 평균 baseline을 사용했습니다.

이 200건은 사기 탐지와 미탐 집단의 비교 표본입니다. 기존 256건의 전체 신청 중요도와 함께 보관하며, 집단별 결과는 해당 집단 안에서 해석합니다. 원래 특성 단위로 signed attribution을 합한 뒤 집단별 평균 절댓값과 평균 signed attribution, 양·음의 기여 비율을 계산했습니다.

이 표본에서 device_os·housing_status·proposed_credit_limit의 평균 양의 기여도는 TP에서 더 컸습니다. current_address_months_count는 FN에서 평균적으로 더 강하게 점수를 낮추는 방향으로 기여했습니다. TP·FN은 이미 예측 점수와 임계값으로 구분한 집단이므로, 이 차이는 해당 표본에서 관측한 모델 설명으로 해석합니다. 원본 특성값 자체의 분포 차이나 사기 발생 원인은 별도 분석이 필요합니다.

## 실행과 검증

저장소 루트에서 기존 전처리 배열과 학교 GPU 체크포인트를 사용했습니다.

```bash
python -m pip install '.[dev,xai]'
OMP_NUM_THREADS=2 baf-evaluate-validation --config configs/midterm.toml
OMP_NUM_THREADS=2 python -m baf.midterm_plots --config configs/midterm.toml
OMP_NUM_THREADS=2 baf-xai-validation --config configs/midterm.toml
OMP_NUM_THREADS=2 baf-xai-cohorts --config configs/midterm.toml
OMP_NUM_THREADS=2 python -m pytest -q
```

실제 로컬 실행은 .venv의 Python과 PYTHONPATH=src를 사용했고, 그림 저장 시 MPLCONFIGDIR=/tmp/baf-matplotlib을 지정했습니다. 패키지를 재설치해 CLI 진입점을 등록했습니다. 평가와 XAI 실행에서 Test 배열을 열면 실패하는 검사를 적용했고 Train·Validation 파일만 열리는 것을 확인했습니다. 동점 임계값, FPR 상한의 최적해, 양성 예측 0건, 파일 해시 불일치, 선형 모델의 IG 완전성, 특성 집계, TP·FN 표본 선정과 통계 테스트를 포함해 전체 71개가 통과했습니다.

평가 예측과 개별 IG 배열은 로컬 npz 파일로 보관합니다. 결과를 같은 설정으로 재실행하면 결과 파일을 갱신하며, 기존 모델 체크포인트는 읽기 전용으로 사용합니다.

## 해석의 범위

이번 수치는 모델 선택에도 사용한 동일한 Validation에서 얻었습니다. 독립 Test 성능은 E4·E5까지 설정을 고정한 뒤 평가합니다. 세 시드의 표준편차는 초기화·학습 순서에 따른 변동이며 독립 데이터셋에 대한 신뢰구간으로 해석할 수 없습니다.

감마 탐색은 E2에 추가 예산을 사용했습니다. 구조 비교에서는 파라미터 수를 비슷하게 맞췄지만 층 수와 너비도 달라 잔차 연결만의 효과를 분리하지 못했습니다. XAI는 전체 신청 256건과 별도 사기 집단 200건의 단일 시드·단일 baseline 분석입니다.

## 후속 일정

11월 26일 중간발표에는 [8분 발표 구성](presentation-notes.md)을 사용합니다. 이후 E4 Random Oversampling, E5 FT-Transformer를 진행하고, 설정과 임계값을 고정한 뒤 B0~E5의 Test 평가, FN 심층 분석, XAI 확장, 최종 보고서를 순서대로 완성합니다. 상세 순서와 완료 조건은 [개발 계획](../../docs/project-status.md)에 있습니다.
